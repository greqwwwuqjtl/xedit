## 🎮 Overview

xEdit (SSEEdit, FO4Edit, etc.) is the definitive modding tool for Skyrim, Fallout 4, and other Bethesda titles, used for cleaning, conflict resolution, and script editing.

Whether you're a newcomer or a veteran, xEdit provides the tools you need to get the most out of your gaming mods experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.

---

## ✨ Key Features

| Feature | Description |
|---|---|
| **Conflict Resolver** | Visual diff highlighting shows every mod override clearly |
| **Cleaning Tool** | Removes dirty ITM records and UDR from ESP/ESM files |
| **Merge Plugin** | Combines multiple ESP files into a single merged plugin |
| **Script Runner** | Execute Pascal scripts to batch-edit records across mods |
